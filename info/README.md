# 📈 Stock Market Prediction & Portfolio Management System (Java)

## 📌 Project Overview
This is a **Java-based Stock Market Prediction and Portfolio Management System** that fetches **real-time stock prices** using an external API, calculates price changes, manages a user’s stock portfolio, and provides **basic trend predictions**.

The project demonstrates how real-world financial applications are built using **APIs, JSON data, and Object-Oriented Programming (OOP)** concepts.

---

## 🎯 Objectives
- Fetch real-time stock market data
- Apply Object-Oriented Programming concepts in Java
- Manage and analyze stock portfolios
- Provide basic stock trend predictions
- Build a simple JavaFX-based dashboard
- Learn Git & GitHub version control

---

## ⚙️ Features
- 📊 Real-time stock price fetching (Finnhub API)

## 🔗 API Used
**Finnhub Stock API**

The application sends HTTP requests to the Finnhub API and receives stock data in **JSON format**, which is parsed and processed within the Java application.

---

## 📊 How It Works
1. Predefined stock symbols are selected
2. Real-time stock prices are fetched via API
3. Percentage price change is calculated
4. Stocks are added to the user portfolio
5. Trend prediction is generated
6. Data is displayed in console and JavaFX dashboard
